What is included?
Every database table and column, including settings, portals, MACs, genres, sources, playlists, fallback links, seasons, episodes, areas, users, Enigma2 profiles, FFmpeg templates, EPG data and logs. Individual-table backups include referenced parent rows automatically. Active-stream records are exported for reference, but are never restored as running streams. Media files, uploaded favicon files, filesystem caches and environment/Docker configuration are not included.

Delete stored data

Permanent and cannot be undone. Download a backup first. Deleting a parent table also removes dependent rows or clears their references; the review below shows the impact. Stop streams and fetch jobs before continuing.

This deletes database contents, not the database schema, media files, uploaded favicon or environment configuration. Deleted settings fall back to defaults. Built-in templates/default settings may be recreated at startup; background tasks can repopulate logs and EPG data.
